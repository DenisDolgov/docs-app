# @docs-app/docs-backend

NestJS-бэкенд монорепо.

## Запуск

Из корня монорепо:

```bash
pnpm dev:backend   # watch-режим, http://localhost:3001
```

## Эндпоинты

- `GET /health` — проверка доступности.

## Конфигурация

Порт задаётся переменной окружения `PORT` (по умолчанию 3001). Env-файлы
создаются локально в этом каталоге и не коммитятся.
