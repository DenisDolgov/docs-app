# Контракт `@docs-app/contracts`

Wire-контракт клиент↔бэкенд: всё, что пересекает границу HTTP или WS. Модули
бэкенда и клиент импортируют отсюда, локальных копий не заводят.

## Что здесь живёт

| Файл | Содержит |
| --- | --- |
| `src/http/index.ts` | конверт ошибок `problemDetailsDto` (RFC 9457) |
| `src/<module>/index.ts` (или `dto.ts`) | zod-схемы входа и ответа |
| `src/<module>/routes.ts` | сегменты/параметры для декораторов + полные пути клиента |
| `src/<module>/roles.ts` | наборы значений-перечислений (источник `pgEnum`) |
| `src/collab/protocol.ts` | WS: путь, opcodes, коды закрытия, `AwarenessChanges` |
| `src/collab/presence.ts` | форма awareness-состояния |

## Правила

1. **Здесь только wire.** Доменные команды, read-модели, DI-токены, сервисные
   тайминги — в бэкенд-модуле. События между сервисами — отдельный IDL при
   извлечении сервисов, не этот пакет.
2. **Зависимости — только `zod` и чистые константы.** Ни Nest, ни Drizzle, ни
   `yjs`/`lib0`: пакет обязан грузиться в браузере и в Node без побочных эффектов.
3. **Собираемый пакет, не source-only.** `tsc` → `dist` (CJS + `.d.ts`),
   `exports` по каждому энтрипоинту. Бэкенд резолвит по `main`/`paths`, фронт —
   по `exports`. `dist` в git не коммитится; `build` гоняется перед typecheck.
4. **Пути — единый источник.** `@Controller(base)`/`@Post(segment)`/`@Param(param)`
   берутся из `routes.ts`, клиентские пути выводятся из тех же сегментов.
   Литеральные пути в e2e-тестах — намеренный независимый оракул, не заменять.
5. **Клиент импортирует осознанно.** Типы — `import type` (стираются). Рантайм-
   константы — только из энтрипоинтов без zod (`/collab/protocol`, `/*/routes`),
   чтобы схемы не попадали в бандл.
6. **Даты в схемах ответа — ISO-строки** (`z.iso.datetime()`), не `z.date()`:
   иначе JSON Schema/OpenAPI не строится. См. `apps/docs-backend/AGENTS.md`.
7. **Перечисления — отсюда.** Набор значений объявляется здесь, `pgEnum` и
   union-тип выводятся из него в бэкенде (`organization/roles.ts` →
   `database/schema/organizations.ts`).
